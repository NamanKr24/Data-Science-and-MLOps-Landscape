# Data Science and MLOps Landscape Analysis

## 📖 Project Overview

What’s shaping the future of data science and MLOps? This project dives into Kaggle’s latest industry survey to uncover where the field is headed. By analyzing real-world responses from thousands of professionals worldwide, we break down patterns in tool adoption, infrastructure preferences, job roles, and AI application areas.

Whether you're a student, practitioner, or decision-maker, this analysis offers a snapshot of the technologies and trends redefining the data ecosystem.

---

## 🎯 Objective

To analyze industry-wide trends in data science and MLOps using a real, large-scale survey dataset. The focus is to extract actionable insights on:
- Tool preferences (languages, frameworks, IDEs),
- Infrastructure usage (cloud, GPUs),
- Employment roles and career patterns,
- Growth areas in machine learning applications.

The project aims to help individuals and teams align their skillsets with industry needs.

---

## 🛠️ Tools and Techniques

- **Language & Environment:** R
- **Libraries Used:** `tidyverse`, `ggplot2`, `dplyr`, `plotly`
- **Workflow:** Data wrangling → feature engineering → interactive visual reporting via R Markdown

---

## 🔍 Key Insights

1. **Employment Shifts:** Rising demand for roles in MLOps and DevOps, beyond traditional data science.
2. **Tool Adoption:** Python dominates, but SQL and R retain niche strength; TensorFlow and PyTorch continue to lead.
3. **Cloud & Hardware:** Strong shift toward cloud platforms (AWS, GCP) and GPU acceleration for scalable ML.
4. **AI Use Cases:** Computer Vision and NLP are leading real-world deployment areas across industries.

## 🧭 How to Use

1. **Clone the Repository**
   ```bash
   git clone https://github.com/NamanKr24/Data-Science-and-MLOps-Landscape.git
   cd Data-Science-and-MLOps-Landscape
   ```

2. **Open the Analysis**

  - Run the Insights.Rmd file using RStudio or another IDE supporting R Markdown.

  - Knit the report to generate Insights.html, which includes interactive plots and summaries.

3. **Explore the Report**

  - Open Insights.html in your browser to navigate visual dashboards and insight sections.
